## From Issue to verified closure

Nibfin uses GitHub Actions to run the work on a Runner when dependencies
and permissions allow it. It waits when those conditions are unmet.

That means less manual handoff between implementation, verification, and
review. You can trace what changed and what passed through the Issue,
pull request, and check results.
