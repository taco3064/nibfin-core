## Reading sample

Nibfin uses indigo surfaces and violet emphasis. Read an [internal link](../),
compare `inline code`, and check the heading hierarchy with keyboard navigation.

- Primary text stays readable on document surfaces.
- Secondary text supports the hierarchy without disappearing.
- Long code scrolls within its own block.
