An adopted public repository can include an optional `.nibfin.json` at its
root. Core reads the file from the Issue's target repository in the current
development worktree, including when a shared Runner executes the Job.

<CardGrid>
  <Card title="Tools" icon="setting">

## Example configuration

All three fields are optional. An absent file uses Nibfin's defaults.
An invalid declaration produces a configuration error before affected work starts.

```json title=".nibfin.json"
{
  "tools": { "node": "22.15.0" },
  "allowedDomains": ["pypi.org", "files.pythonhosted.org"],
  "skills": {
    "shape": { "mode": "extend", "path": ".nibfin/skills/shape/SKILL.md" },
    "deliver": { "mode": "override", "path": ".nibfin/skills/deliver/SKILL.md" }
  }
}
```

## What applies to each Job

### Tools

Use exact versions from the
[maintained tool catalog][tool-catalog].
Core prepares and reuses verified tool images for supported backends. Each admitted
Job selects the environment for its target repository. The versions apply to the
isolated Agent and applicable offline hooks. Host tools and concurrent Jobs keep
their own environments. An unavailable version stops the affected work.

### HTTPS destinations

Use complete DNS names. Extra destinations apply only to the target Job via
Core's existing proxy. Wildcards, IP addresses, custom ports and plain HTTP are
outside this interface. The Runner must have the required proxy support.
An already-running Job keeps the policy admitted at launch.

### Role Skills

Configure `shape`, `deliver`, or `accept` with a repository-relative Markdown
file. `extend` appends the file to the default Skill, while `override` uses only
the selected file. An unreadable or unsafe path stops the affected role.
Changes to role instructions remain subject to Core's execution and merge rules.

:::note[Verification boundary]
Project configuration, per-Job HTTPS policy, Skill customization, tool image
preparation, and Job environment selection are present in Core source. Formal
release and support on a specific installed Runner require their own evidence.
:::

[configuration reference][project-config].
