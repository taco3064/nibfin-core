## Configuration review

For either owner type, review the target Public Repository, intended member,
applicable protections, actual required checks, workflow permissions and repository
Runner policy with the authorized administrator. Keep credentials out of Issues,
documentation and Agent workspaces. Use verified immutable source identities and
approved component pairing, not a floating branch as a release pin.

Review the installation PR through protected merge. Initial optional Runner
registration happens only after that PR has merged and requires Repository Admin
authority. See [registration paths](../runners/#registration-paths).
An installed candidate in one reviewed configuration is not a formal release or
certification of fresh-user installation.
